# Helmet Violation Detection

An AI-powered computer vision system that analyzes moving dashcam videos to detect traffic violations involving two-wheelers.

## Features

- 🏍️ Detect motorcycles and scooters
- 👤 Detect riders
- 🪖 Detect whether the **driver** is wearing a helmet
- 👥 Detect triple riding
- 📸 Capture evidence images with bounding boxes and labels
- 📝 Generate local violation logs

## Tech Stack

- Python
- PyTorch (CUDA)
- OpenCV
- YOLO
- ByteTrack (later)
